PUBLISH FOR FREE:
1. Create a GitHub account and a new public repository.
2. Upload index.html, style.css and script.js.
3. Create/sign in to Vercel and import that GitHub repository.
4. Deploy as a static site. No build command is needed; the output directory is the repository root.
5. Vercel will provide a vercel.app URL.
